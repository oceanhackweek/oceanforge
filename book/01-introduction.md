# Introduction to the JupyterHub

Our JupyterHub is a cloud-based compute environment designed to support
hands-on, reproducible workflows for ocean and earth science.

It provides browser-based access to common scientific tools such as
JupyterLab, RStudio, and the command line, without requiring local
installation.

This book introduces the hub, explains how to get started,
and provides guidance on common workflows used during OceanHackWeek
events and similar training activities.

## What is JupyterHub?

JupyterHub is a platform that allows many users to access computational
environments through a web browser. Each user gets their own server
with a personal workspace, while sharing underlying infrastructure.

JupyterHub supports multiple interfaces, including:
- JupyterLab
- RStudio
- Terminal access

All interfaces operate on the same filesystem.

## How to use this book

This book is intended as a practical guide rather than a complete
programming reference.

You do not need to read it linearly. Chapters are designed to stand on
their own, and you can jump directly to topics relevant to your
workflow.

The examples and instructions here are written for OceanForge, but
many concepts apply to other JupyterHub-based systems.
